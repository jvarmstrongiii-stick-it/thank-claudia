# thank-claudia

Voice-first field service management app for Tyler's HVAC.

Built for technicians in the field and admins in the office.

## What it does

- Voice-driven job intake — add and update jobs hands-free
- Open jobs dashboard with status tracking and revenue visibility
- Full job lifecycle management from estimate to paid
- Customer history, equipment records, and photo capture
- Admin view with drag-and-drop prioritization

## Stack

- **Frontend:** React Native (mobile) + React web (admin)
- **Backend:** Node.js
- **Database:** Supabase
- **AI:** Claude API (voice intake + OCR)
